# Dango Music 1.7.5 更新日志

发布日期：2026-11-10。

## 新增

- 均衡器：播放栏上的竖条按钮。10 段（32Hz～16K，±12 dB），前级增益自动压低，开大了也不爆音；11 个预设（平直、低音增强、重低音、高音增强、人声、摇滚、电子、古典、响度、V 形、夜间）。
- 变速变调：播放栏上的调音按钮。速度 0.5x～2x（音高不变），音调 -12～+12 半音（速度不变）；"音调跟着速度"像黑胶变速。歌词和进度条跟着变速后的时间走，一起听时速度固定 1x。
- 按歌记住：这首歌下次放还用这套均衡、速度和音调。
- 显示其它播放器正在放的歌（设置 → 音乐 → 其它播放器，默认关，Windows 10 及以上）：Dango 自己没在放歌时，灵动岛、Song card、歌词和播放栏显示 Spotify、Apple Music、网易云桌面版等正在放的歌，配上音源就有歌词和封面；播放栏的按钮会转给那个 App，歌词偏移可调。
