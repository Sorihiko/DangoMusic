# Dango Music 1.7.3 更新日志

发布日期：2026-11-04。

## 新增

- 歌手页：点歌手名看热门歌曲、专辑和简介，网易云 / QQ 音乐 / 酷狗都支持。
- 局域网 / 内网穿透联机时，一起听直接经房主的游戏同步，不用 Firebase、不用代理（双方都要装这个 mod）。
- 云盘：网易云 / QQ 音乐 / 酷狗登录后可以听自己云盘里的歌。
- 支持 FLAC 和 Ogg Vorbis 格式。
- 悬浮的液态玻璃播放栏，进度条可以按住拖动；播放器窗口可以拖边缘改大小、拖顶部移动。
- 设置里新增「音频输出」：自动 / Java Sound / 游戏声音。安卓自动用游戏声音，不用再加启动参数。
- 歌曲播放失败时自动跳到下一首。

## 调整

- 音量均衡改成按歌曲实际音频计算。
- 一起听成员点歌时，把整个列表交给房主。

## 修复

- 1.8.9 歌词不发光。
- 开启「保持在屏幕内」时，睡觉、第三人称视角下歌词位置不对。
- 酷狗部分歌曲无法播放。
- 3D 歌词导致明显掉帧（1.20.1 / 1.21.1 / 1.21.11 / 26.x）。
- 用游戏声音放歌时，按 F3+T 或拔插耳机会跳歌。
- 部分声卡上音量调节无效。
- 环境音效把树冠当成墙壁。
- 房主关闭「允许成员控制」后，成员仍能切歌、暂停。
