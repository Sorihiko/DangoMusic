# Dango Music 1.7.4 更新日志

发布日期：2026-11-09。

## 新增

- 支持 Minecraft 1.21.10（Fabric / NeoForge）。
- 放歌时原版背景音乐自动暂停，歌停了再照常放。

## 调整

- 26.1.2 版也能装在 26.1 和 26.1.1 上。
- 酷狗个人歌单按酷狗 App 里的顺序显示。

## 修复

- 紫水晶等安卓启动器放不出歌。
- 放歌时切换输出设备（连上蓝牙耳机等）后歌停住，按播放也恢复不了。
- 开着环境音效时，低音重的歌在室内会爆音。
- 开光影时画面偶尔白闪。
- 1.21.11 开 F3 或在歌曲信息里切换页面时，灵动岛闪一下。
- 启动日志里报 `Shader not found: outline/base.vert`。
